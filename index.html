How to install

Each plugin is a self-contained package: download the .zip, upload it with Plugin Manager or unpack it into the plugins folder, and activate it in System > Plugins. The plugins create their own folders on first use and keep their data in the filestore, so updates never delete settings.

Download

Get the .zip of the latest release from the plugin page.

Upload

Upload it with Plugin Manager, or unpack it into the plugins folder on the server.

Activate

Activate the plugin in System > Plugins and open its Options. Only administrators can use the plugin pages.

Update

Upload the new .zip and choose Overwrite – settings stay in the filestore.
